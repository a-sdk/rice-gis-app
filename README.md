# Rice GIS App

## Project Description

This project is a software application designed to process aerial imagery from drones to generate spatial distribution maps.

## Key Features

1. Load GeoTIFF raster imagery.
2. Load vector data such as shapefiles and GeoPackages.
3. Create and draw polygons.
4. Process GeoTIFF rasters using machine learning models.
5. Display spatial distribution maps generated by machine learning model predictions.
6. Provide distribution information and action recommendations.


## Installation Guide

Follow these steps to run the project on your local machine.

### Prerequisites

Ensure you have downloaded the file (`.zip`/`.tar.gz`) containing the application and its internal folders.

### Installation

1. Extract the ZIP file into your local directory.
2. Run the application and wait for the user interface to launch.
